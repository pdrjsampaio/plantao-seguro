## Como instalar no Android

1. Baixe o arquivo pelo link acima.
2. Abra o APK no celular e confirme a instalação.
3. Se o Android solicitar autorização para instalar aplicativos dessa fonte, verifique a procedência do arquivo antes de permitir.
