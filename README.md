# Plantão Seguro

Aplicativo Android **Plantão Seguro**.

## Baixar o aplicativo

Os arquivos de instalação para Android (.apk) serão disponibilizados na seção [Releases](https://github.com/pdrjsampaio/plantao-seguro/releases) deste repositório.

> **Atenção:** o instalador `app-debug.apk` é uma compilação de desenvolvimento/testes. Para distribuição definitiva, prefira um APK de release assinado.

## Instalação no Android

1. Na seção **Releases**, baixe o arquivo APK da versão desejada.
2. Abra o arquivo no celular e confirme a instalação.
3. Se o Android solicitar autorização para instalar apps dessa fonte, avalie a origem do arquivo antes de permitir.
